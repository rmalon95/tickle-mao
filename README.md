# Tickle Mao
Tickle Mao Tse-Tung to make him laugh! But don't tickle him too much!

## How to Play
1) Install [Godot 4.6.2.stable](https://godotengine.org/download/archive/4.6.2-stable/)
2) [Download game](https://github.com/rmalon95/tickle-mao/archive/refs/heads/main.zip) and unzip
3) Open project in Godot
4) Press F5
